# Hodowcy — prototyp 0.1

Samodzielna strona HTML bez instalacji i bibliotek. Otwórz `index.html` w przeglądarce lub opublikuj na hostingu statycznym.

Działa: losowa plansza 19 heksów, wierzchołki, początkowe ustawianie 3/4 graczy, zasięg 3 krawędzi, karty startowe, rzuty i produkcja, blokada inspektora.

Jeszcze nie działa: pełne tury, handel, hotele, ulepszenia, medale, wydarzenia, pełne rozliczenie siódemki, multiplayer i zapis gry. Kolejność spirali numerów oraz sąsiedztwo 6/8 wymagają walidacji przed wersją docelową.
